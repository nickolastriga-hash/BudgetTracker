# Expo SDK 57

This project runs Expo SDK 57 (upgraded 2026-09-04 from a temporary SDK 54 pin — see CLAUDE.md's
"SDK 54 → 57 upgrade" bullet for why the pin existed and what the upgrade touched). Docs at
https://docs.expo.dev/versions/v57.0.0/ match what's actually installed; check that URL's version
segment before trusting an Expo doc page or example found elsewhere, since APIs (NativeTabs' icon
props, in particular) have changed shape across recent SDKs.
